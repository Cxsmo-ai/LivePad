# Security policy

## Reporting a vulnerability

Please do not publish credentials, tokens, private logs, or a working exploit
in a public issue. Use a private GitHub security advisory for sensitive reports
or contact the repository owner through the GitHub profile.

Include the affected version, Windows version, reproduction steps, and the
smallest safe proof of impact. Redact usernames, channel names, cookies, and
access tokens.

## Scope

Security reports involving chat parsing, extension permissions, named-pipe
handling, bridge lifecycle, packaging, or unintended game access are welcome.
LivePad intentionally does not implement game inspection or anti-cheat bypass.
