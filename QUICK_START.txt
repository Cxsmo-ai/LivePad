STREAM PLATFORMS (USE TOGETHER OR ON THEIR OWN)
----------------------------------------------------------------------
1. TikTok LIVE:
   - Check "[x] Enable TikTok Stream"
   - Type your TikTok username (e.g. @yourname)
   - Click "Connect TikTok"

2. YouTube LIVE (Powered by youtube-chat-next engine):
   - Check "[x] Enable YouTube Stream"
   - Enter your channel handle (e.g. @LofiGirl), video URL, or channel ID
   - Select Chat View: "Live Chat (all messages)" or "Top Chat"
   - Click "Connect YouTube"

3. Twitch:
   - Check "[x] Enable Twitch Stream"
   - Enter the public Twitch channel username (e.g. channel_name)
   - Click "Connect Twitch"
   - No Twitch password is requested or stored. The connector uses the
     current anonymous read-only Twitch IRC WebSocket path.
   - Normal Twitch bot-style prefixes work: "!shoot" is treated as
     "shoot", and "!w sprint ads fire" runs the full compound command.
   - Twitch officially guarantees IRC access only with OAuth chat:read;
     if anonymous access changes, the app reports the rejection clearly.

4. Combined Mode (Together):
   - Check any combination and click "CONNECT ALL ENABLED".
   - Comments from all enabled platforms flow into one unified controller!
   - Every comment in the Unified Chat displays its platform logo:
     * TikTok cyan/magenta note logo for TikTok comments
     * YouTube red badge logo for YouTube comments
     * Twitch purple chat logo for Twitch comments

----------------------------------------------------------------------
COD ZOMBIES & FPS COMMAND LIST
----------------------------------------------------------------------
1. Interaction, Buying & Reviving (Button X):
   interact         - Hold Button X (800ms) to open doors / buy wall weapons
   buy              - Hold Button X (800ms) to buy Mystery Box / Perks
   use              - Hold Button X (800ms) to use traps / assemble parts
   revive           - Hold Button X (1500ms) to revive downed teammates
   x                - Press Button X (300ms, or 'x 1000' to hold for 1000ms)
   reload           - Tap Button X (120ms) to reload current weapon

2. Movement (Left Analog Stick):
   w / forward      - Move forward (Left stick UP)
   s / back         - Move backward (Left stick DOWN)
   a / left_strafe  - Strafe left (Left stick LEFT)
   d / right_strafe - Strafe right (Left stick RIGHT)
   sprint           - Click left stick (L3 / Sprint)
   slide            - Slide (Hold Button B for 400ms)
   crouch / b       - Crouch (Button B)
   jump             - Jump / Mantle (Button A)

3. Camera & Aiming (Right Stick with Analog Modifiers):
   left             - Look left (default 40% strength, 150ms)
   right            - Look right (default 40% strength, 150ms)
   up               - Look up (default 40% strength, 150ms)
   down             - Look down (default 40% strength, 150ms)

   Number Modifiers (Strength % 1-100):
    NO '%' SYMBOL NEEDED: Just write the bare number!

     right 25       - Turn right gently (25% stick deflection)
     right 50       - Turn right medium (50% stick deflection)
     right 75       - Turn right fast (75% stick deflection)
     right 100      - Turn right maximum (100% stick deflection)

   Duration Modifiers:
     right 50 250   - Turn right at 50% deflection for 250 ms
     left 75 400    - Turn left at 75% deflection for 400 ms
     w 1.2s         - Move forward at default 100% speed for 1.2 seconds
     w 500ms        - Move forward at default 100% speed for 500 ms
     x 1000         - Hold Button X for 1000 ms

   Per-action strength and time in one combo:
     w 80 1.2s sprint ads fire 100 300ms right 35 250ms jump 200ms

   How Combos and Omitted Strengths Work:
     - "w 80 1.2s sprint": Moves forward at 80% for 1.2s while activating sprint (L3).
     - "w 1.2s sprint": Moves forward at default 100% for 1.2s while activating sprint (L3).
     - "w sprint": Moves forward at default speed for default time while activating sprint.
     - If strength is not typed before a duration (e.g. "w 1.2s"), strength automatically
       uses the configured default!

   Read each digital button action as:
     command  duration

   Seconds vs. Milliseconds Toggle:
     - Checkbox in GUI: "Enable seconds duration (e.g. 1.2s, 0.5s) — uncheck for ms only"
     - When checked: Chat viewers can write either seconds (1.2s) or ms (250ms / 250).
     - When unchecked: Chat only accepts milliseconds (ms), ignoring/rejecting 's' suffixes.
     - Strength must be 1-100; duration must be 25-1500ms.

4. Combat & Weapons:
   fire / shoot     - Pull Right Trigger (RT 100%)
   ads / aim        - Pull Left Trigger (LT 100%)
   swap / switch / y- Switch weapon (Button Y)
   melee / knife    - Melee strike (Right Stick Click / R3)
   tac / tactical   - Left Bumper (LB)
   nade / grenade   - Right Bumper (RB)

5. Controller Tester & Extra Xbox Buttons:
   The Resolved Controller State panel is a live gamepad tester. It shows
   exact LX, LY, RX, RY, LT, and RT values plus every standard button:
   A/B/X/Y, LB/RB, L3/R3, View, Start, Guide, and all D-pad directions.

   start / menu     - Start / Menu button
   view             - Back / View button ("back" remains move backward)
   guide             - Xbox Guide button
   dpadup            - D-pad Up
   dpaddown          - D-pad Down
   dpadleft          - D-pad Left
   dpadright         - D-pad Right

   The stick dots move to the exact resolved position. Active controls
   illuminate cyan, triggers fill proportionally, and D-pad diagonals show
   both directions at once. This always displays the final combined state
   sent to HIDMaestro, not merely the last chat command received.

----------------------------------------------------------------------
COMPOUND COMBOS (CONCURRENT INPUT LEASES)
----------------------------------------------------------------------
Viewers can type multiple actions together:
  w sprint
  ads fire
  w fire
  w sprint ads fire right 35
  w interact
  slide jump

When a viewer types:
  w sprint ads fire right 35

All 5 actions activate at the exact same instant!

----------------------------------------------------------------------
SAFETY FEATURES & CONTROLS
----------------------------------------------------------------------
- Emergency Kill Switch (F12): Press F12 anywhere to immediately pause
  chat and neutralize all controller inputs.
- PAUSE CHAT: Temporarily ignores incoming stream comments.
- CLEAR CONTROLLER: Immediately centers sticks, releases buttons/triggers.
- Hardware Watchdog: If Python freezes, the C# bridge resets the
  controller to neutral within 1000 ms.
